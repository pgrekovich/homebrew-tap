# Homebrew tap for Simstim

```sh
brew install --cask pgrekovich/tap/simstim
```

Simstim records and transcribes calls locally on Apple Silicon Macs and keeps
them as Markdown files. Source, releases and documentation:
https://github.com/pgrekovich/simstim

The cask installs the same signed, notarized disk image as the GitHub release.
Notes stay in the folder you chose; `brew uninstall --zap` also removes the
app's configuration and downloaded speech models.
